# Conventions for 4ENote

- Kotlin, Jetpack Compose (Material 3), Room. Android app for tablets.
- Open-source libraries only (check the license before adding any dependency); no Google Play
  services, no ML Kit, no tracking or analytics.
- Match the surrounding code: comment density, naming, idioms. Comments explain why, in plain
  English; no comments that just restate the code.
- Keep changes focused on the task. Don't reformat or rename unrelated code.
- Unit tests live in app/src/test (JUnit 4); run them with `./gradlew testDebugUnitTest`.
  Instrumented tests (app/src/androidTest) only ever run on the emulator, never on a real device.
- Never put secrets in the code (the Google client id is in local.properties, which is not committed).
- No AI attribution anywhere: no "Co-Authored-By", no "generated by" lines.
